3. Detailed Work Package Implementation & Architecture

3.1 Finite State Machine Implementation — user_lifecycle_fsm.py

Engineered the core user state machine governing transitions between 7 operational states. Prohibited invalid leaps (e.g., direct transition from UNREGISTERED to ENGAGED without completed onboarding events). Added edge-case handling for sequential timestamp sorting and duplicate session locks.

3.2 Cohort Retention & Matrix Generation — cohort_retention.py

Engineered cohort calculation routines that aggregate users by weekly registration cohorts and compute return ratios over rolling time horizons. Integrated normalized matrix exports for dynamic Plotly and Seaborn heatmap visualization within the executive dashboard.

3.3 Cryptographic PII Masking & Data Governance — pii_masking.py

Implemented column-level privacy rules adhering to GDPR Article 32 and HIPAA Safe Harbor guidelines:

  • Irreversible Salted Tokenization: User IDs and phone numbers are converted to fixed-length SHA-256 hashes with isolated salt keys.
  • Format-Preserving Pseudonymization: Emails are sanitized to k***0@gmail.com, preserving domain distributions for cohort analytics while preventing personal identification.
  • Zero-Leakage Assurance: Verified that raw PII columns are fully excluded from analytical data marts and public dashboard feeds.

3.4 dbt Dimensional & Fact Models — dbt_project/models/marts/

Authored enterprise SQL models to ensure analytics engineering scalability:

  • dim_user_lifecycle.sql: Generates the dimensional user table containing lifecycle designations, tenure days, and lifetime engagement score.
  • fct_user_retention.sql: Computes cohort survival rates and retention percentages using SQL window functions.
  • schema.yml: Added automated schema test assertions enforcing primary key uniqueness and non-null constraints.

3.5 Streamlit Multi-Tab Executive Dashboard — dashboard_app.py

Deploys a responsive analytics interface featuring:

  • ⭐ Mentor Review Mode: A curated presentation mode that hides dense internal registers and raw error logs, displaying only polished executive KPIs, lifecycle charts, and cohort heatmaps.
  • Interactive Slice Filters: Dynamic sidebar dropdowns allowing stakeholders to slice metrics instantly by Platform (Android, iOS, Web) and Acquisition Channel.
  • Authenticity Badging: Explicitly renders SIMULATED DATA — CREATED FOR ANALYTICAL TESTING badges to maintain data governance transparency.
