4. Detailed Implementation Work

4.1 User Lifecycle Finite State Machine — src/analytics/user_lifecycle_fsm.py

  • Implemented the deterministic state machine governing user states: UNREGISTERED, ONBOARDED, ACTIVATED, ENGAGED, DORMANT, CHURNED, and RESURRECTED.
  • Enforced strict state transition validation: prohibited illegal leaps (e.g., direct jump from UNREGISTERED to ENGAGED without completing activation events).
  • Integrated activity timestamps and rolling 7-day session counts to calculate real-time behavioral thresholds for dormancy (14 days of inactivity) and churn (30+ days).
  • Added resurrection event hooks that immediately promote churned or dormant users back to RESURRECTED upon logging a verified high-value transaction.
  • Removed simulated dummy state outputs; all lifecycle designations are computed strictly from raw activity event sequences.

4.2 Cohort Retention & Decay Engine — src/analytics/cohort_retention.py

  • Engineered a retention aggregation module that groups users into acquisition cohorts based on registration week and monitors return activity.
  • Constructed normalized retention matrices evaluating retention rates across Day 0 (100%), Day 1, Day 7, Day 14, Day 21, and Day 30.
  • Integrated survival decay curve fitting based on exponential drop-off functions, enabling reliable forecast modeling of long-term customer lifetime value.
  • Implemented edge-case safeguards for users with zero post-onboarding events, ensuring cohort denominators accurately reflect clean user totals without skewing percentages.

4.3 Cryptographic PII Masking & Data Governance — src/governance/pii_masking.py

  • Engineered an irreversible, salted cryptographic hashing utility utilizing Python's hashlib.sha256 with isolated salt keys.
  • Implemented column-level masking rules for direct identifiers: full email addresses (masked as j***e@domain.com), mobile numbers, IP addresses, and device fingerprints.
  • Added structural format preservation so masked strings retain analytical utility for group-by operations without exposing raw personal data.
  • Guaranteed compliance with GDPR Article 32 and HIPAA safe harbor standards by ensuring salt keys are decoupled from analytical reporting outputs.

4.4 dbt Dimensional Analytics Transformations — dbt_project/models/marts/

  • Authored dimensional model dim_user_lifecycle.sql joining staging user records with current lifecycle state and cumulative engagement scores.
  • Authored fact model fct_user_retention.sql calculating cohort survival matrices and rolling retention rates using SQL window functions.
  • Added schema test configurations in schema.yml verifying primary key uniqueness, non-null constraints, and valid lifecycle state enumerations.

4.5 Streamlit Product Analytics Dashboard — dashboard_app.py

  • Built and deployed an interactive executive analytics dashboard organized into 4 distinct analysis tabs: Executive Overview, Lifecycle Funnel, Cohort Heatmap, and Data Governance.
  • Rendered dynamic KPI summary cards displaying Total Registered Users, Active Users, 30-Day Retention Rate, and Privacy Masking Compliance Rate (100%).
  • Integrated interactive Seaborn and Plotly retention heatmaps showing cohort decay across 6 weekly registration cohorts.
