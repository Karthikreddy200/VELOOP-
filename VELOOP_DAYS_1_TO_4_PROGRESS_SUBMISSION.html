3.2 A2. User Action Flows vs. System Outcomes

Every feature was decomposed into discrete client actions and server validation gates: * Task Earning Lifecycle: $$\text{Task Viewed} \longrightarrow \text{Task Opened} \longrightarrow \text{Task Started} \longrightarrow \text{Task Completed} \longrightarrow \text{Validation Passed} \longrightarrow \text{Reward Credited}$$ * Withdrawal Lifecycle: $$\text{Withdrawal Requested} \longrightarrow \text{Under Review} \longrightarrow \text{Processing} \longrightarrow \text{Completed / Rejected}$$

3.3 A3. Distinguishing User Events, System Events, and Business Outcomes

To prevent conflating client clicks with financial consequences: 1. User Event (Client): task_completed, withdrawal_requested (Untrusted client telemetry). 2. System Event (Server): task_validation_passed, reward_credited, withdrawal_completed (Atomic backend ledger mutations). 3. Business Outcome (Macro): Day-30 Retention Rate, Net Token Liability, Customer Acquisition Cost (Derived analytics).

3.5 Top 10 Critical Analytics Gaps Identified

Based on cross-referencing simulated data against production requirements, 10 mission-critical gaps were identified: 1. Absence of a Double-Entry Transaction Ledger Table (Critical): Wallet activity exists only as a UI click. Impossible to audit balances or track monetary liabilities. 2. Absence of a Normalized Withdrawal Lifecycle Entity (Critical): Zero cash-out data exists in the current system, blinding management to payout fulfillment. 3. Severed Referral Attribution Linkage (Critical): Users have referral codes, but no relational link ties referrer to referee across registration and activation. 4. Missing Task Validation & Bot Telemetry (Critical): No system validation events exist to distinguish genuine users from autoclickers. 5. Lack of Event Idempotency Keys (High): Raw events lack client UUIDs, making the platform vulnerable to duplicate reward counting on network retries. 6. Inconsistent Feature Casing in Telemetry (High): Mixed casing (missions vs Missions) fragments SQL aggregations. 7. Granular Onboarding Funnel Missing (High): Onboarding is tracked as a static boolean; intermediate step drop-offs are invisible. 8. Conflation of "Activity Occurred" with "Reward Credited" (High): Task completion is erroneously assumed to equal immediate wallet credit. 9. Raw PII Storage in Analytical Layer (High): Plaintext emails and names stored in user tables violate GDPR/DPDP privacy mandates. 10. Missing Session Timeout Instrumentation (Medium): Sessions lack background/foreground heartbeat pings.
